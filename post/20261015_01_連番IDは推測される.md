# 投稿文

連番IDをURLに出すと、数字を変えて他人のレコードを叩かれる。

Railsは signed_id で署名付きのIDを発行し、find_signed で検証しながら引ける。署名が合わなければ nil が返るので、推測では届かない。

expires_in（有効期限）と purpose（用途の限定）も付けられる。
